# اسم المشروع (My Madar Tech Website)
.صفحة تعريفية متكاملة وعصريّة لمؤسسة مدار تك (مساحة عمل مشترك ومؤسسة تعليمية وتدريبية في خان يونس)، تهدف إلى التعريف بالمؤسسة، خدماتها، برامجها التدريبية، وتوفير تجربة مستخدم سلسة واحترافية .

## التقنيات المستخدمة 🛠️
* HTML5
* CSS3 / Flexbox & CSS Grid
* JavaScript
* Bootstrap

## مميزات المشروع 🌟
* تصميم متجاوب مع جميع الشاشات (Responsive).
* واجهة مستخدم بسيطة وجذابة
* أقسام متكاملة تشمل:
* شريط التنقل (Navbar) والشعار.
* الواجهة الرئيسية (Hero Section)
* قسم من نحن (الرؤية والرسالة)
* الخدمات ومساحات العمل والقاعات التدريبية.
* البرامج التدريبية (Front-End, AI, Digital Skills)
* ميزات المؤسسة (لماذا مدار تك؟)
* نموذج التواصل المباشر مع ربطه بتطبيق واتساب
* تذييل الصفحة (Footer) وبيانات التواصل الرسميّة
